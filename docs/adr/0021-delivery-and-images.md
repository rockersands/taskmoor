# ADR-021: One multi-arch image, a static frontend, Compose and Helm kits, signed air-gap bundle

- Status: Accepted
- Date: 2026-10-12
- Backlog: M0-024, M0-025, M0-026

## Context

Self-hosting is a release gate (build plan section 3): backend only, fresh VM to admin login in
under 10 minutes on 2 vCPU / 4 GB; the frontend on any static host (OPS-013); air-gapped
installs from a signed bundle (OPS-005); Docker, Podman and Kubernetes on amd64 and arm64.

## Decision

- **One backend image** (`tracksmith/tracksmith`), multi-arch, under 400 MB, running the role
  named by `TRACKSMITH_ROLE`: `api`, `worker`, `realtime` or `all` (the default, for small
  installs). Every role has `/health` and `/ready`. Configuration is environment variables
  validated at start; secrets may come from files (`*_FILE`).
- **An all-in-one image** (`tracksmith/allinone`) bundles Postgres for trials and single-box
  installs, with the data on one volume; it is the same backend image plus a supervised
  Postgres, never a different codebase.
- **The frontend is static files** built per release, published as a zip and a single-file
  `index.html`, and also served by the backend in single-server mode (OPS-017). No server-side
  rendering.
- **Kits** are generated by the Builder (ADR-031): Compose with Postgres and Caddy for
  automatic HTTPS (the default), Helm values for Kubernetes (HA in M2), and a single binary
  without Docker in M2 (OPS-023).
- **Air-gap bundle:** image archives, frontend builds, the Builder page, checksums, CycloneDX
  SBOM and Sigstore signatures; zero outbound connections by default (no telemetry, no update
  check), local AI models only.
- **Supply chain:** images are built in CI from a pinned lockfile, scanned (Trivy) and signed
  (cosign); the SBOM ships in the release (ADR-029).

## Options considered

| Option | For | Against |
|---|---|---|
| One image with roles (chosen) | One artifact to build, scan, sign and upgrade; roles scale separately on Kubernetes | Image carries code for every role (small cost) |
| One image per role | Smaller images | Version skew between roles; three builds and scans |
| Separate air-gapped edition | Simpler online build | Plane's split edition forces reinstalls; two codebases |

## Consequences

The nightly install matrix (M0-028) runs the kits on Ubuntu 22.04 and 24.04, Debian 12 and
RHEL 9 on amd64 and arm64, and the no-egress test proves the air-gap claim on every release.
