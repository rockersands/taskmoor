# Security policy

Tracksmith is pre-release software. No version is supported for production use yet.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: open the repository's **Security** tab
and choose **Report a vulnerability**. Do not open a public issue.

Include what you found, how to reproduce it and the impact you expect. You will get an
acknowledgement within 7 days and a fix or mitigation plan within 30 days for confirmed issues.

## Scope

In scope: the backend, the web frontend, the Builder and its generated kits, install scripts and
container images published from this repository.

Out of scope: third-party services an administrator connects (identity providers, mail, AI
providers), and self-hosted instances run by others.
